# Техническая спецификация: Модернизация и редизайн фронтенда

- **Дата**: 2026-10-17
- **Проект**: Universal Viral Hunter
- **Статус**: Approved by user, ready for planning
- **Архитектурный путь**: Нативный модульный ES6+ (HTML5 + CSS + ES Modules), нулевые изменения в Docker-инфраструктуре

---

## 1. Проблема и цели

### 1.1 Текущие проблемы
1. **Сетевой оверхед от видео**: В монолитном `index.html` все видео рендерятся через активные теги `<video controls preload="metadata"><source src="...">`. При наличии десятков постов браузер отправляет параллельные `Range`-запросы на подгрузку метаданных и буферов, перегружая сервер и подвешивая интерфейс.
2. **Монолитный файл `index.html`**: Файл размером 303 КБ (>6350 строк) объединяет CSS, разметку и всю логику приложения в глобальной области видимости `window`, что делает развитие и поддержку крайне трудоёмкими.
3. **Громоздкая шапка**: Шапка занимает 3 уровня (~180px по высоте), забирая значительную часть экрана у рабочего контента.
4. **Фиксированный вид карточек**: Нет гибкости при просмотре — невозможно быстро просканировать медиа-контент без чтения длинных полотен текста.

### 1.2 Цели редизайна
- **Click-to-Play Lazy Video Facade**: 0 байт предварительной загрузки видеопотока. Скачивание и запуск видео только по явному клику пользователя на кнопку Play.
- **Модульная архитектура ES6+**: Декомпозиция монолита на чистый семантический HTML-каркас (<300 строк), модульный CSS и изолированные ES-модули.
- **100% сохранение Docker**: Никаких Node.js/npm зависимостей в продакшн-контейнере.
- **Компактная шапка (Single-line Header)**: Объединение строки статусов, логотипа и действий в компактный блок (~80px с табами).
- **Переключатель видов (View Switcher)**:
  - **Режим «Медиа-Сетка»**: компактные карточки с акцентом на медиа, оверлей русского текста при наведении курсора (`hover`), заголовок и метрики.
  - **Режим «Лента редактора»**: развернутый вид с полным текстом, тезисами и тегами для финализации перед публикацией.

## 2. Архитектура и структура файлов

Все статические файлы располагаются в `src/web/static/` (маршрут `/static` уже настроен в `src/web/server.py`):

```
src/web/static/
├── index.html                     # Минималистичный HTML-каркас (шапка, табы, модалки)
├── css/
│   ├── variables.css              # Dark Telegram палитра, типографика, радиусы, тени
│   ├── base.css                   # Сброс стилей, лейаут, утилиты
│   ├── header.css                 # Компактная двухрядная шапка и статусные пилюли
│   ├── components.css             # Кнопки, табы, бейджи, тосты, тумблер режимов
│   ├── cards.css                  # Сетка постов, карточки, оверлей текста при hover
│   ├── video-facade.css           # Стили обложки видео, стеклянная кнопка Play, плеер
│   └── modals.css                 # Модальные окна (редактирование, ИИ-инструкции)
└── js/
    ├── app.js                     # Точка входа: инициализация, роутер табов, переключатель вида
    ├── api.js                     # REST API клиент (/api/queue, /api/settings, /api/topics)
    ├── toast.js                   # Легковесные анимированные уведомления
    ├── video-player.js            # Компонент Click-to-Play, single-player policy, IntersectionObserver
    ├── cards.js                   # Генератор HTML-карточек (режимы Grid и Feed)
    ├── queue.js                   # Логика вкладки очереди (сортировка, публикация, удаление)
    ├── published.js               # Логика вкладки архива опубликованных
    ├── modal.js                   # Редактирование поста, счетчик символов, перегенерация через ИИ
    ├── topics.js                  # Управление топиками и фильтрами
    └── settings.js                # Управление настройками системы и видео-параметрами
```

## 3. Компонент плеера Click-to-Play (`video-player.js`)

### 3.1 Спецификация состояний
1. **Idle / Facade**:
   - Рендерится обертка `.video-facade` с атрибутом `data-video-src="${vidSrc}"`.
   - Внутри находится `<img class="video-facade-poster" src="${posterUrl}" loading="lazy">`.
   - По центру накладывается стеклянная кнопка `.video-play-btn` с иконкой Play.
   - В левом верхнем углу — бейдж `🎬 ВИДЕО`.
   - В правом верхнем углу (для режима Сетки) — кнопка быстрого разворота в полный экран.
2. **Active / Playing**:
   - По клику вызывается `activateVideoPlayer(containerEl)`.
   - Все остальные ранее запущенные видео ставятся на паузу (`Single-Player Policy`).
   - Содержимое `.video-facade` плавно замещается на нативный `<video controls autoplay playsinline>`.
   - Инициализируется `IntersectionObserver`: если видео уезжает за пределы экрана при скролле более чем на 70%, оно автоматически ставится на паузу.

## 4. Компактная шапка и переключатель видов

### 4.1 Шапка
- **Ряд 1 (Высота 44px)**:
  - Слева: Логотип `⚡ Viral Hunter` + компактный бейдж версии `v2.1`.
  - По центру: Живые статусы `ИИ: ОК`, `Pipeline: Idle`, системные часы сервера.
  - Справа: Кнопка быстрого запуска `[ ▶ Scout ]`, плашка пользователя `👤 User` и кнопка выхода.
- **Ряд 2 (Высота 38px)**:
  - Слева: Табы навигации (`План публикаций`, `Опубликованные`, `Топики`, `Настройки`, `Дайджест`).
  - Справа: Тумблер вида сетки:
    - Кнопка `⊞ Сетка` (активирует компактный режим с ховер-оверлеем).
    - Кнопка `☰ Лента` (активирует подробный режим редактора).
    - Состояние сохраняется в `localStorage.getItem('vh_view_mode')`.

### 4.2 Режимы отображения карточек
- **Класс контейнера сетки**: `.posts-grid.mode-grid` или `.posts-grid.mode-feed`.
- **В режиме `mode-grid`**:
  - Карточка имеет фиксированное соотношение и компактную высоту.
  - Под медиа отображается только заголовок, автор и Viral Score.
  - При наведении курсора мыши на медиа снизу выдвигается `.card-text-overlay` с размытием `backdrop-filter: blur(8px)`, показывая русский перевод твита.
  - Кнопка Play доступна поверх оверлея.
- **В режиме `mode-feed`**:
  - Полный развернутый текст, блок `📌 Главное`, список хештегов и полный набор кнопок перемещения/редактирования всегда открыты.
